
# George Maina Portfolio

A simple personal portfolio website for George Maina, a web developer based in Kenya.

## Overview

This project is a single-page portfolio built with plain HTML and CSS. It includes:

- Hero section with introduction
- About section
- Services section
- Contact section
- Responsive layout for mobile and desktop

## Files

- `index.html` — main page structure and content
- `assets/george-maina.png` — profile image
- `.vscode/` — editor configuration

## Run locally

Because this is a static site, you can open `index.html` directly in a browser.

Alternatively, serve it locally with a simple HTTP server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
